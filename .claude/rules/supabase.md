# Supabase 연동 규칙 (데이터 계층)
- **포인트·펀딩 상태 변경은 클라이언트에서 직접 write 금지.** 잔액 차감·지분 배정·정산·
  마감 처리는 서버 RPC(Postgres 함수)만 호출한다. 클라이언트는 결과를 받을 뿐 계산·기록의
  주체가 아니다. (동시성·원자성·포인트 총량 보존은 서버 트랜잭션 책임)
- **service_role 키는 클라이언트에 절대 노출 금지.** 브라우저 번들에는 anon 키만. 서버 전용
  키가 필요한 연산은 RPC/서버 측에 둔다. (게이트 NO_HARDCODED_SECRET가 1차로 잡지만 배치도 규칙)
- **RPC 응답은 신뢰 경계 밖.** shared/api는 반환값을 그대로 도메인에 넘기지 말고 경계에서
  파싱·검증한다 (스마트 컨스트럭터로 도메인 값 객체 생성).
- 이 파일은 범용 연결/호출 어댑터만 — 도메인 개념(펀딩 규칙, 정산 공식)은 여기 두지 않는다
  (그건 entities/features). shared 규칙과 동일: 도메인 지식 유입 금지.
