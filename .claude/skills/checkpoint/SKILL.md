# 체크포인트 — 텍스트 합의는 시각 의도를 담지 못한다
## 절차
1. 시작 전 projects/<이름>/docs/design/design-rules.md를 읽는다 (이전 승인 누적분이 기준)
2. 범위를 명시적으로 좁힌다: 대표 페이지 1개 또는 사용자 지정 범위까지만
3. 제출 시 함께 제공: 로컬 확인 방법 + 봐야 할 요점 2~3개
4. 명확히 묻는다: "레이아웃/색/톤 중 어긋난 게 있나요?"
5. 피드백 → 반영 계획 요약 → 동의 → 수정 → 재제출
6. 승인되면 확정 기준을 projects/<이름>/docs/design/design-rules.md에 추가하고, 파일 상단 프론트매터를
   `status: approved`로 둔다 (이후 작업의 기준 + 게이트 design/BEFORE_UI가 UI 구현을 허용하는 신호)
## 금지
- 승인 전에 나머지를 "미리" 만들어두지 않는다 — 방향이 바뀌면 전부 재작업
