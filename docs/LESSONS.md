## 2026-07-24 — RLS 격리는 구조 검증만으론 불충분

- 증상: 정책 표현식(academy_id=current_academy_id())이 스펙과 일치해 "검증 통과"로 봤으나, security definer
  함수의 `set search_path=public`이 pg_temp 섀도잉을 못 막아 격리가 실제로는 우회 가능했다.
- 교훈: (1) 모든 security definer 함수는 `set search_path=''` + 스키마 완전 한정. (2) RLS/인가는 정책이 "있다"가
  아니라 두 테넌트 세션으로 "새지 않는다"를 행동으로 증명해야 한다. (3) 프리미티브 함수(current_academy_id 등)는
  적대적 입력(temp table 섀도잉)까지 테스트.

## 2026-08-05 — 물어보는 목록에 없으면 "합의된 적 없는 기본값"이 들어앉는다

- 증상: kickoff 가 묻는 항목을 열거하는데(`렌더링(정적/SPA)`, 데이터 계층, 배포) 그 목록에 UI 프레임워크가
  없었다. 답이 PRODUCT.md 에 "프레임워크/렌더링: Vite + SPA + FSD — 확정"으로 남았고, 칸 이름에 "프레임워크"가
  들어 있어 **묻고 답한 것처럼 보였다.** 실제로 정해진 건 SSR 여부뿐이고 UI 프레임워크는 스캐폴드 기본값
  (vanilla DOM)이 조용히 메웠다. 사용자가 코드를 처음 열어본 날 발견 — 화면 20개 2,431줄 재작성.
- 교훈: (1) 인터뷰에서 **묻는 항목을 열거하는 자리**는 빠뜨림이 곧 무단 결정이 된다 — 목록 자체가 계약이다.
  (2) 한 칸에 두 결정을 뭉치면(빌드 도구 + UI 프레임워크) 절반만 답해도 다 답한 것처럼 보인다.
  (3) 사용자가 문서를 인용해 되물으면("~라고 써 있지 않았나?") 그건 문서가 잘못 읽히고 있다는 신호다.
- 반영: `.claude/skills/kickoff/SKILL.md` — UI 프레임워크를 묻는 항목에 추가 + PRODUCT 기술 결정을 두 줄로 분리.

## 2026-08-05 — 검사 장치는 자기 자신이 바뀐 것을 못 본다

- 증상: `gates/spec-coverage.mjs` 가 커밋 없이 예전 버전으로 되돌아가 **봉인 검증(inv_hash 대조)이 통째로
  빠진** 상태였는데, 게이트는 계속 "통과"라고 말했다. 그 상태로 세션 내내 7~8회 "게이트 통과"를 보고했고,
  그 사이 approved 스펙의 INV 를 근거로 코드를 고쳤다. 발견은 순전히 우연(커밋하려다 git status 에서 봄).
- 교훈: (1) 게이트의 "통과"는 **게이트가 온전할 때만** 의미가 있다. 자기 무결성을 안 보는 검사는 조용히
  약해질 수 있다. (2) 하네스 파일의 후퇴는 코드 리뷰·테스트·게이트 어디에도 안 걸린다 — 감시할 자리가
  따로 필요하다. (3) 실패가 아니라 경고로 둔다: 하네스를 고치는 중에는 더러운 게 정상이다.
- 반영: `scripts/briefing.mjs` — 세션 시작 시 `gates/`·`.claude/rules/`·`.claude/agents/`·`scripts/seal-spec.mjs`
  의 미커밋 변경을 첫 화면에 띄운다.

## 2026-08-05 — 도구가 없는 판단은 시키지 않는다

- 증상: 리뷰어 3종의 tools 가 `Read, Grep, Glob` 뿐이라 git 히스토리를 못 보는데, 전환 리뷰에서 셋 다
  "회귀냐 기존이냐"를 추측으로 분류했다. 결과: 기존 버그 6건을 회귀로 잘못 분류, 정작 전환이 만든 회귀
  2건은 아무도 못 짚음. 셋 다 "셸이 없어 대조하지 못했다"고 스스로 적어놓고도 판정은 내렸다.
- 교훈: 에이전트에게 **가진 도구로 불가능한 판단**을 요구하면 침묵하는 게 아니라 그럴듯하게 지어낸다.
  능력 밖 판단은 프롬프트에서 명시적으로 금지하고, 그 판단은 도구를 가진 쪽이 맡는다.
- 반영: `.claude/agents/{code,security,ui}-reviewer.md` — "회귀 판정 금지, 현재 코드의 결함으로만 보고.
  기존/신규 판별은 위임한 쪽이 git 으로 대조" 한 블록.
