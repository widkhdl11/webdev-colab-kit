# design-rules.md — 승인된 디자인 기준 (checkpoint가 누적)
> UI 작업 전 필독. 여기 있는 기준이 개별 취향보다 우선한다.
> 모든 색·간격 값은 src/shared/ui/tokens.css 의 CSS 변수로만 참조한다(하드코딩 금지).

## 2026-07-08 · 홈(펀딩 목록) checkpoint 승인 — 전역 시각 언어 확정

**톤**
- 차분한 신뢰감(펀딩 사이트) + 아기자기함(부드러운 라운드·따뜻한 muted 색·친근한 카피)의 균형.
- "통통 튀는"(고채도 무지개·쨍한 강조 남발)은 회피한다. 색은 아껴 쓴다.

**색**
- 단일 브랜드 강조 = 묵직한 인디고 `--brand: #4a45b8`. 강조색은 **진행률 바 · 주요 CTA · 잔액 pill**에만.
- 퍼센트 등 데이터 숫자는 강조색이 아닌 뉴트럴 텍스트(`--text`). 색으로 튀게 하지 않는다.
- 의미색(semantic)은 accent와 분리: 진행중=은은한 브랜드 틴트 배지, **달성=solid 초록(축하 모멘트만 또렷하게)**, 무산=은은한 danger 틴트.
- 썸네일은 채도 낮춘 톤 색면 그라데이션(카테고리별 색감은 유지, 캔디 금지). 추후 이미지 업로드로 대체 가능.

**형태**
- 라운드: 카드 `--r-lg`(14px), 칩·배지·pill은 `--r-full`. 값은 토큰으로.
- 그림자는 얇게(`--shadow-card`), hover 리프트는 최소(-2px, `--shadow-hover`).

**타이포**
- 시스템 폰트 스택(`--font`), 본문 16px 이상. 정렬되는 숫자는 `tabular-nums`.
- 헤딩은 굵게(800)·자간 타이트. 헤딩엔 `text-wrap: balance` 권장.

**레이아웃**
- sticky 헤더(로고 레터마크 · 내비 · 잔액 pill · 데모 계정) + `--maxw`(1080px) 중앙 정렬 + auto-fill 카드 그리드.
- 이 레이아웃 언어를 상세 페이지·개설 폼이 물려받는다(반복은 빠른 경로).

**접근성**
- 본문 대비 4.5:1 이상. 진행률은 `role="progressbar"` + aria 값. 폼은 label 연결. 포커스 가시 상태 유지.
