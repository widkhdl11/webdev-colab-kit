# PRODUCT.md — 만들 제품 (정의 + 스코프)

> 제품 정의+스코프 문서(프로젝트당 1개). 스코프가 바뀔 때만, 사용자 동의로 갱신한다.
> 필수 기능은 체크박스로 관리 — 브리핑이 진행률로 집계. 각 기능의 동작·불변식은 docs/specs/ 스펙에 산다.

## 한 줄 요약

학원 선생님들이 학원 단위로 학생의 시간표·월간 평가·시험 성적을 공유·관리하고,
월간 평가표를 이미지/PDF로 내보내며, 과목별·시험별 성적 통계를 보는 학생 관리 사이트.

## 목적과 대상

- 목적: 학원 학생의 등록·시간표·월간 평가·시험 성적 관리 (학원 단위 공유)
- 대상: 한 학원에 소속된 선생님들 (로그인 사용자). 여러 과목 선생님이 같은 학생을 담당·평가

## 필수 기능

- [x] 로그인 / 회원가입 + 학원 생성·참여 → docs/specs/auth-isolation.md (approved)
- [ ] 학생 등록 / 수정 → docs/specs/student-registration.md
- [ ] 학생별 시간표 등록 → docs/specs/schedule.md
- [ ] 학생·과목별 월간 서술 평가 → docs/specs/evaluation.md
- [ ] 월간 평가표 이미지/PDF 내보내기 → docs/specs/evaluation-export.md
- [ ] 시험별 점수 입력 + 성적 이력 → docs/specs/exam-score.md
- [x] 과목별·시험별 성적 통계 → docs/specs/stats.md (approved)
- [x] 학원 단위 데이터 격리 → docs/specs/auth-isolation.md (approved)

## 선택 기능

- (미정) — 후보: 학원 구성원 관리, 다크 테마

## 비범위 (만들지 않는 것)

- (미정) — 후보: 학생/학부모 로그인, 결제, 알림/문자

## 페이지 구성

- 회원가입 / 로그인 (+ 학원 생성 / 참여)
- 학원생 목록
- 학생 상세 (시간표 + 월간 평가 이력 + 시험 성적 + 평가표 내보내기)
- 학생 평가 입력 (월간 서술) / 시험 점수 입력
- 학생 등록 / 수정
- 성적 통계 (과목별·시험별 그래프/목록)

## 기술 결정 (프리셋: TypeScript + FSD — 하네스 전제)

- 프레임워크/렌더링: **Vite + SPA + FSD** — 확정
- 데이터 계층: **Supabase** — 학원 격리는 서버(RLS)가 강제
- 인증: Supabase Auth (이메일/비밀번호) _(가정)_
- 배포: 정적 호스팅 _(가정 — 미확정)_

## 디자인 방향

- docs/design/design-rules.md 참조 (checkpoint로 승인된 시각 기준)

## 참고

- 평가는 두 종류: **월간 서술 평가**(학부모용, 이미지/PDF) + **시험별 점수 이력**(통계용). 둘 다 유지.
- 학생 개인정보(미성년자) 취급 → 학원 단위 접근 제어가 핵심 불변식.
