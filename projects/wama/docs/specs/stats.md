## 사용자 이야기 🔓
- 학원 선생님으로서, 학원 전체·과목별·학년별로 **정기시험 성적이 시험을 거치며 어떻게 움직이는지** 한 화면에서 보고,
  특정 시점을 눌러 **학생 순위**로 파고들고 싶다. 왜냐면 상담·지도 전에 성적 추이와 잘/못한 지점을 빠르게 파악하려고.

## 동작 🔓

### 흐름
- 통계 페이지 진입 → 탭 3종(**전체 / 과목별 / 학년별**) 중 선택 → 해당 집계를 본다. (승인 시안 stats.html)
- **전체 탭**: 요약 카드 + 전체 평균 추이(꺾은선, 정기시험 시점 순) → 포인트 클릭 → 그 시점 학생 평균 순위표(드릴다운).
  기본은 최신 정기시험 시점이 선택된 상태로 대표 표시.
- **과목별 탭**: 과목 하나 select → 그 과목의 정기시험 점수 변화(꺾은선).
- **학년별 탭**: 현재 학년별 최근 정기시험 평균(막대).

### 대상 시험 (분류)
- **정기시험(중간·기말)** = 통계의 본선. 시간축 = (연도, 학기, 중간/기말) 순서.
  저장값에서 파생: `exam.period`("YYYY 학기" — 입력 폼의 연도·학기 select로 생성되는 고정 형식)에서 연도·학기,
  `exam.kind`에서 중간/기말. (자유 타이핑 아님 → 파싱 안정적. 스키마 변경 불필요.)
- **비정기(학원시험 등, 정기·모의 제외)** = 정기와 **분리된 별도 영역**에서 본다(부정기라 정기 시간축 격자에 안 맞음).
  구체 배치는 추후(현 승인 시안엔 없음 — 비범위 참조).
- **모의고사** = 이 스펙 범위 밖. 추후 학생 개인 그래프에서 정기 대비 **보조선**으로 (비범위 참조).

### 시간축·순서
- 정기시험을 (연도 오름차, 학기 오름차, 중간 → 기말) 순으로 늘어놓는다.
- 아직 치르지 않은(점수 없는) 시점은 축에서 제외. 최신 = 점수 있는 마지막 정기 시점.
- 작년 같은 학기·종류(예: 25년 1학기 기말 ↔ 26년 1학기 기말)는 (학기, 종류)가 같아 연도 간 비교가 가능하다.

### 집계 규칙
- 점수는 집계 전 **백분율**로 환산한다: (score / max_score) × 100. 만점이 다른 시험을 원점수로 섞지 않는다. → INV-ST2
- 평균은 **학생 동등 가중**: 먼저 학생별로 그 시점 과목 백분율의 평균을 내고, 그 **학생 평균들의 평균**을 낸다.
  과목 점수를 전부 더해 개수로 나누지 않는다(다과목 학생 과대반영 금지). → INV-ST3
- **미응시(점수 미입력) 항목은 집계·그래프에서 제외**하고 0점으로 치지 않는다. → INV-ST4
- 과목은 저장된 이름 **문자열 그대로** 묶는다. 과목 목록에서 rename해도 과거 기록 문자열은 안 따라가므로,
  다른 문자열은 다른 과목으로 잡힌다(병합·정규화 안 함 — 비범위). <!-- 횡단 결정: subject 자유문자열(DECISIONS 2026-07-25) -->
- 학년별 집계의 학년은 **조회 시점 현재 학년**(파생값, 저장 스냅샷 아님)으로 묶는다. 시점별 학년 재계산은 하지 않는다.
- 드릴다운 순위: 선택한 정기 시점의 학생별 평균(백분율) 내림차순.

### 입력과 검증
- 통계는 **읽기 전용** — 이 페이지에서 데이터를 쓰지 않는다. 사용자 입력은 탭 전환·과목 select·포인트 클릭뿐.

| 입력 | 필수 | 규칙 | 어기면 |
|---|---|---|---|
| 탭 선택 | Y | 전체/과목별/학년별 중 하나(기본: 전체) | — |
| 과목 select(과목별 탭) | Y | 학원 과목 목록에서. 목록 비면 빈 상태 안내 | 그래프 대신 "과목 없음" |
| 시점 포인트 클릭(전체 탭) | N | 점수 있는 정기 시점만 클릭 가능 | — |

### 성공 / 실패
- 성공: 선택한 탭의 집계가 그래프·표로 보인다. 값 라벨은 백분율.
- 데이터 없음(정기시험 점수 0건): "표시할 정기시험 성적이 없습니다" 빈 상태 — 오류 아님.
- 로드 실패(네트워크 등): 오류 메시지 + 재시도. **부분 집계로 오해할 값은 표시 금지**(빈손이 틀린 숫자보다 낫다).

### 규칙
- 색만으로 정보 의존 금지 — 모든 포인트·막대에 값 라벨(디자인 규약).
- 숫자는 tabular-nums, 백분율 단위 표기.

## 불변식 🔒 (계약 — 승인 후 변경은 재승인 필요)
- INV-ST1: 통계 집계는 요청자 학원(current_academy_id())으로 스코프된 exam·exam_score·student 만 포함한다.
  타 학원 데이터는 어떤 그래프·순위·평균에도 들어갈 수 없다. (강제: 서버 RLS — auth-isolation 정책; service_role·우회 조회 금지) — 위반 시: 타 학원 미성년자 성적 유출.
- INV-ST2: 점수는 집계 전 백분율((score/max_score)×100)로 환산한다. 만점이 다른 점수를 원점수 그대로 합산·평균하지 않는다. (강제: 집계 구현 + 테스트) — 위반 시: 만점 상이 시험이 뒤섞여 평균이 거짓이 된다.
- INV-ST3: 전체·과목·학년 평균은 학생별 평균을 먼저 내고 그 평균들을 평균한다(학생 동등 가중). 과목 점수 총합 ÷ 과목수로 내지 않는다. (강제: 집계 구현 + 테스트) — 위반 시: 다과목 학생이 과대반영되어 평균이 왜곡된다.
- INV-ST4: 점수가 입력되지 않은 항목(미응시)은 집계·그래프에서 제외하며 0으로 대체하지 않는다. (강제: repo 필터 + 테스트) — 위반 시: 미응시가 0점이 되어 평균이 부당하게 하락한다.

## 시나리오 (각각 어느 불변식 검증인지 ID 참조 — 실패 경로 필수)
- S1 (INV-ST1): Given 두 학원 A·B에 각각 학생·정기시험 점수가 있다 / When A 소속 선생님이 통계를 연다 / Then 그래프·순위·평균에 B의 어떤 점수도 포함되지 않는다(A 스코프만).
- S2 (INV-ST2): Given 한 시점에 국어 80/100(=80%)과 수학 40/50(=80%) / When 평균을 낸다 / Then 둘 다 80%로 환산돼 평균 80% (원점수 (80+40)/2=60 이 아님).
- S3 (INV-ST3): Given 학생 A는 3과목(각 90%), 학생 B는 1과목(60%) / When 전체 평균을 낸다 / Then (90+60)/2 = 75%(학생 동등)이지 (90×3+60)/4 = 82.5% 가 아니다.
- S4 (INV-ST4): Given 학생 B가 이번 정기시험에 점수 미입력 / When 그 시점 평균·순위를 낸다 / Then B는 그 시점 집계에서 빠지고, 0점으로 평균을 끌어내리지 않는다.

## 신뢰 경계
- 믿는 값: 서버 RLS가 학원으로 스코프해 돌려준 행(격리는 서버가 강제).
- 안 믿는 값: 클라이언트가 보낸 필터·학원 식별자(최종 격리는 RLS가 재확인), 클라이언트에서의 미응시·환산 판단(집계 로직이 재확인).

## 비범위
- 학생 개인 성적 그래프(정기 대비 모의고사 보조선 비교) — 추후.
- 모의고사 통계 — 추후(개인 그래프).
- 비정기(학원) 통계의 구체 화면·배치 — 추후(현 승인 시안에 없음).
- 과목 이름 병합·정규화(별칭) — 하지 않음(문자열 그대로).
- 시점별 학년 재계산·연도 간 동일 학년 비교("작년 중3 vs 올해 중3") — 하지 않음(현재 학년 스냅샷).
